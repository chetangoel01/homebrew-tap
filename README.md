# Homebrew Tap

Casks for apps by Chetan Goel.

## Meeting Recorder

```bash
brew install chetangoel01/tap/meeting-recorder
```

Upgrade with `brew upgrade meeting-recorder`. Source and releases:
https://github.com/chetangoel01/meeting-recorder

## Cooler

```bash
brew install chetangoel01/tap/cooler
```

Fan curves and menu bar temperatures for the 16-inch M1 Max MacBook Pro.
Upgrade with `brew upgrade cooler`. Source and releases:
https://github.com/chetangoel01/cooler
